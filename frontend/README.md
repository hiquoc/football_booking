# PitchUp Frontend

Next.js App Router frontend for the football booking platform.

## Local development

1. Copy `.env.example` to `.env.local` and set the API gateway URL.
2. Start the backend gateway and its dependent services.
3. Install dependencies with `npm install`.
4. Run `npm run dev` and open `http://localhost:3000`.

The current development OTP is `111111`.

## Verification

Run `npm run lint`, `npm run typecheck`, `npm test`, and `npm run build` before merging.
